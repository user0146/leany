## ⚠️ ルール

1. **作業開始前**
* 最新状態を取得(PULL)
2. **作業中**
* VS Codeで編集
3. **作業終了** 
* Commit・Push
* 提出 Pull Request 


-------
****他の人が更新した後は必ず最新状態を取得（PULL）****
詳細は下に↓

--------
## ① 📥 最初の準備（一番最初だけ）
ネット上にあるフォルダ一式を、自分のパソコンに丸ごとダウンロードします。

1. **Gitをインストールする**
   * ※まだ入れていない人だけ、ネットで「Git インストール」と検索して自分のパソコンに入れておいてください。
2. **VS Codeを開く**
3. **検索窓を開く**
   * キーボードの `Ctrl` と `Shift` を押しながら、`P` を押します（Macは `Cmd + Shift + P`）。
4. **「ダウンロード」**
   * 検索窓に **「Git: クローン」** と入力して、出てきた文字をクリックします。
5. **URLをコピーする**
   * ネットでみんなのページを開きます。
   * 右上にある緑色の **「Code」** ボタンを押し、**「HTTPS」** の下にあるアドレスをコピーします。
6. **URLを貼り付ける**
   * VS Codeの検索窓にアドレスを貼り付けて `Enter` を押します。
7. **保存する場所を決める**
   * パソコンの「デスクトップ」などを選んでボタンを押します。
8. **フォルダを開く**
   * 画面の右下に「開きますか？」と出るので、**「開く」** をクリックします。

---

## ② 🔄 作業を始める前に（毎回、絶対にやること！）
他の人が新しく作った最新のデータを自分のパソコンに取り込みます。**これを取り忘れて上書きすると、他の人の作品を消してしまうので注意してください！**

1. **最新のデータをもらう（Pull / プル）**
   * VS Codeの左メニューにある **「枝分かれしたアイコン（ソース管理）」** をクリックします。
   * 上の方にある **「...（三点リーダー）」** ボタンを押し、メニューから **「プル（Pull）」** をクリックします。

---

## ③ ✏️ コードを書き換えて、画面をチェックする

### 🔹 コードを書く
* 自分が担当するファイル（htmlファイルなど）を開いて自由に書き換えます。
* 書き換えたら、キーボードの `Ctrl + S`で**必ず保存**してください。

---

## ④ 📤 完成した作品をネット（GitHub）に直接送る
作業が終わったら、書き換えたファイルをみんなの「main」に一発でアップロードします。

1. **送る画面を開く**
   * VS Codeの左メニューにある **「枝分かれしたアイコン（ソース管理）」** をクリックします。
2. **「これを取り込んで！」と箱に入れる**
   * 変更したファイルの名前の右横にある **「＋ (プラス)」マーク** をクリックします。
3. **メモ（メッセージ）を書く**
   * 上にある入力欄に、何をしたかメモ（例: `トップページの色を変えました` など）を書きます。
4. **ネットに送り出す（コミット＆プッシュ）**
   * メモを書いたら、すぐ下にある青い **「✓ コミット」** ボタンを押します。
   * その後に出る青い **「変更の同期（Sync Changes）」** というボタンを押します。

> 💡 これで、あなたの作業内容が直接みんなの「main」に合体し、GitHubに保存されます！
